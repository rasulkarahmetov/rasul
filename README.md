# 💎 ProBank Evolution Premium

*ProBank Evolution* — это современное десктопное приложение для управления банковскими счетами, разработанное на языке Java. Приложение сочетает в себе строгую бизнес-логику и премиальный пользовательский интерфейс в темных тонах.

## 🚀 Основные возможности

### 🏦 Управление счетами
* *Сберегательные счета:* Классическое хранение средств с возможностью пополнения и снятия.
* *Кредитные счета:* Умная система управления задолженностью. Автоматический расчет процентов и установка сроков погашения в месяцах.
* *Начисление процентов:* Массовое начисление бонусных процентов на все сберегательные счета одной кнопкой.

### 📊 Аналитика и Контроль
* *Dashboard:* Интуитивно понятная панель ввода данных клиента (ФИО, Телефон, Сумма).
* *История транзакций:* Полное логирование всех действий (депозиты, снятия, создание счетов) с указанием точного времени.
* *Статистика:* Мгновенный расчет суммарного капитала банка и распределение типов счетов.
* *Приватность:* Функция «Скрыть баланс» для защиты конфиденциальных данных на экране.

### 🛡️ Безопасность
* *Авторизация:* Доступ к системе только для зарегистрированных сотрудников.
* *Персонализация:* Возможность смены логина и пароля администратора через внутренние настройки.

## 🛠️ Технологический стек
* *Language:* Java 17+
* *GUI Framework:* Swing / AWT (Custom UI Design)
* *Time API:* Java.time (для управления сроками кредитов)
* *Persistence:* File-based system (txt базы данных)

## 🎨 Дизайн
Приложение выполнено в стиле *Premium Dark*:
* *Палитра:* Глубокий антрацитовый и фиолетовый акцент (Accent Purple).
* *UI элементы:* Кастомные закругленные кнопки (RoundButton), стилизованные таблицы и современные карточки ввода.

## 📁 Структура проекта
* Account.java — Базовый абстрактный класс.
* SavingsAccount.java / CreditAccount.java — Логика конкретных типов счетов.
* BankService.java — Ядро системы: хранение данных, логирование, операции со счетами.
* Main.java — Основной интерфейс приложения.
* LoginFrame.java — Окно входа и точка запуска.

## 🔧 Установка и запуск
1. Склонируйте репозиторий.
2. Откройте проект в вашей IDE (IntelliJ IDEA, Eclipse).
3. Запустите класс LoginFrame.
4. Используйте стандартные данные для входа: admin / 1234.
